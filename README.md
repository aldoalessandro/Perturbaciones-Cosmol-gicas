
# Perturbaciones cosmológicas

Este repositorio contiene cálculos simbólicos desarrollados en Wolfram Mathematica para el estudio de las perturbaciones cosmológicas a primer orden sobre un fondo FLRW.

## Contenido

El archivo `CPT_es.nb` incluye el cálculo de la métrica inversa, los símbolos de Christoffel, el tensor de Ricci, el escalar de curvatura y el tensor de Einstein en el gauge longitudinal.

Se utiliza la signatura métrica \((- + + +)\), con \(\Psi\) como potencial temporal y \(\Phi\) como potencial espacial.

## Procedencia

El notebook se basa en una adaptación del material de cálculo simbólico de Daniel Baumann, ajustado a las convenciones empleadas en el proyecto de tesis sobre perturbaciones primordiales durante la inflación cósmica.

## Software

Wolfram Mathematica.

## Referencia

Baumann, D. (2022). *Cosmology*. Apuntes de cosmología.
